**# Flashcard Quiz App

A simple web app for studying with flashcards. Built for the CodeAlpha App Development internship (Task 1).

## Features
- Question on the front, answer revealed with a "Show Answer" button
- Navigate between cards with "Next" and "Previous"
- Add, edit and delete flashcards
- Cards are saved in the browser (localStorage), so they stay after a refresh
- Clean, responsive interface

## Technologies
HTML, CSS, JavaScript

## How to run
Open `index.html` in any browser, or visit the live demo: <https://gbordjuerpriscilla.github.io/flashcard-quiz-app/>
